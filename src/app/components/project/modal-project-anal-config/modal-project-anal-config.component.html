Analysis Configuration
File analysis mode :

With Deep mode, file analysis is based on binwalk only. It provides best results than Simple mode, especially with polyglot and huge files, but is if 3x slower than Simple mode.

With Smart mode, a first pass is done with Simple Mode. Next, unknow files are scanned with binwalk. Finally, files containing textual data are parsed speculatively.

With Simple mode, file analysis is based on file headers only. On UNIX-like systems, the command file is called. Polyglot files cannot be detected, but is if 3x faster than Deep mode.
